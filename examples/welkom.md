# Welkom bij de markdown viewer

Deze viewer leest **markdown** uit een map naar keuze. Kies links een bestand en
het document verschijnt direct. Met `Ctrl+O` open je een andere map.

## Wat kan het?

- Door mappen bladeren en markdown-bestanden openen
- Wisselen tussen bestanden met één klik of de pijltjestoetsen
- Relatieve links naar andere `.md`-bestanden volgen
- Tabellen, codeblokken en afbeeldingen tonen

> De interface blijft bewust klein: een lijst, een document, en een zoekveld.

## Een codeblok

```bash
qmake6 markdown-viewer.pro && make
./build/markdown-viewer ~/notities
```
